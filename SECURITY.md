# Security

Decision Check is a set of instructions for Claude Code. It reads files in the project you run it in, can run read-only searches and commands, may search the web, and saves reports to `decision-reports/`. It never modifies your code.

If you find a way the skill could be made to leak private code or data, run unsafe commands, or follow instructions planted in a repository or web page, please report it privately to **khaiwalsanyam07@gmail.com** instead of opening a public issue. You'll get a reply within a week.
